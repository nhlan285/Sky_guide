# Production-safe Wardrobe demo V1

`manifest.json` is a dedicated `self_created_demo` package, not the public Sky catalog and not the Phase 0 SVG test fixture. All geometry was newly drawn for this editor; every asset remains `placeholder=true`, `fixture=true`, `legalStatus=self_created_placeholder`, with synthetic IDs and no source/download paths. K13/full assets remain **pending legal confirmation**.

The fictional `demo-model-wayfarer` / `demo-model-r1` uses a normalized 0–1 viewBox, top-left origin, x right and y down. Four `fixture-demo-size-*` presets are self-created proportions, not in-game sizes. Config, assets, bindings and calibration have explicit revisions. JSON anchors stay unscaled; the renderer applies binding scale locally, then character scale once on the enclosing group. SVG maps that coordinate system to the viewport.

Twelve fictional items cover the six project slots, each with capacity 1. Both capes have rear and front bindings. Fabric/panel dye uses declared inline mask geometry and a six-color palette; missing masks preserve the original color. Revision r2 includes the fictional tile-mask -> small-preset rule with a visible reason and fixture disclosure. Removing/replacing it restores the chosen base scale. Conflicting candidate actions keep the accepted outfit and expose rule IDs; missing calibration has a specific warning. State uses a pure reducer with explicit replacement and keeps base/effective size separate.

The bounded r1->r2 compatibility helper keeps all old item/size/dye IDs and revalidates each snapshot; effective state is recomputed. Existing r1 library keys are retained, with in-memory projection on read and current revision written only on explicit save. Exact old demo share links remain supported; unknown versions/items still reject. This is not generic alias/tombstone migration.

Scoped P6-U03 backup exports only validated saved demo outfits as bounded JSON. Import previews the count and requires explicit library replacement; clearing requires confirmation. Both preserve the editor draft and other preferences. Future-version/quota failures retain existing storage protection; no QR/private data or full-localStorage dump is exported. File download and read require browser capabilities; manual visual/file-picker QA remains separate.

`validation.ts` validates this dedicated demo entry point on module load. The editor route loads the package once, independently of the public catalog/export pipeline; it never imports `tests/fixtures/wardrobe/`. Local save/rename/delete/reload and compressed versioned demo sharing are implemented (P4-W09/P4-W10). P4-H01 adds a memory-only draft across SPA navigation; reload still restores only explicit saves. Catalog item entry explains unavailable rendering and never maps a real item to a fictional lookalike. Verified game compatibility is not provided.

Verification: `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build`. No browser automation is used. **MANUAL VISUAL CHECK REQUIRED**: Daylight/Sunset/Night, Vietnamese/English, equip/replace/remove, all scale presets, palette/reset, narrow mobile panels, landscape and landing scrollbars.
